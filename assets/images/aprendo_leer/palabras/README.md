# Imágenes de palabras — Aprendo a leer

Ilustración 3D de cada palabra de ejemplo de las sílabas. **Mientras falte una, la app muestra un marcador «Imagen pendiente»** (nunca una imagen que pueda confundir) y esa palabra no se usa en el juego «Une sílaba y palabra».

Formato: WEBP cuadrado de 512 × 512, fondo limpio, **sin texto**, la figura centrada y fácil de reconocer por un niño de 4 a 7 años. Nombre exacto del archivo; después, `python3 tools/reading/syllables.py`.
