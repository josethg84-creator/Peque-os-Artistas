# Ilustraciones 3D de las medallas

Pendientes: la app dibuja ahora cada medalla con un círculo, una cinta y un icono (no son emojis).
Cuando exista el archivo, se podrá usar como ilustración definitiva.

Formato: WEBP cuadrado (512×512), fondo transparente, estilo 3D suave como el resto de la app, sin texto.
