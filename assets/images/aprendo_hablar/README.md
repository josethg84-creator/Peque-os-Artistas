# Imágenes — Aprendo a Hablar

Coloca aquí las siete ilustraciones individuales de las tarjetas del módulo, preferentemente en formato WebP:

- `mis_primeras_palabras.webp`
- `aprendo_frases.webp`
- `juegos_de_palabras.webp`
- `construyo_oraciones.webp`
- `mi_historia.webp`
- `yo_puedo_expresarme.webp`
- `aprendo_los_verbos.webp`

Después, registra la carpeta `assets/images/aprendo_hablar/` en la sección `flutter.assets` de `pubspec.yaml` y actualiza las tarjetas para usar `Image.asset`.

Este archivo README mantiene la carpeta visible en GitHub incluso antes de subir imágenes.
