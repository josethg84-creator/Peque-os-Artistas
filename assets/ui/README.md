# Ilustración de inicio

Sube aquí la imagen optimizada **pequenos_artistas_inicio.webp**.

El nombre y la ruta deben ser exactamente:
`assets/ui/pequenos_artistas_inicio.webp`

La pantalla `lib/screens/home_screen.dart` muestra esta imagen y superpone
zonas táctiles proporcionales para Colorear, Mini Juegos, Actividades, Galería,
Perfil, Logros, Configuración y música. Los botones se mantienen funcionales
aunque la ilustración sea una imagen estática.

Mientras falte el WEBP, se muestra un diseño alternativo en Flutter.
La referencia original tiene proporción 2:3.

No incluir fotografías reales de menores ni recopilar datos personales.
