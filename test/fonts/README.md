# Fuentes para pruebas

Roboto (Regular, Medium, Bold y Black), la fuente que usa Android por defecto, copiada del
SDK de Flutter (`dart-sdk/bin/resources/devtools/.../fonts/Roboto`). Licencia Apache 2.0
(Google). Solo la cargan las pruebas que miden textos reales
(`test/narrow_phone_test.dart`); la app no la empaqueta.
