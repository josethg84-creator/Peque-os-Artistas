# Imágenes de palabras — Aprendo a leer

Ilustración 3D de cada palabra de «Aprendo a leer». **Mientras falte una, la palabra no se usa en los juegos de imagen** (en «Aprendo las sílabas» se ve un marcador «Imagen pendiente», nunca una imagen que confunda).

Formato: WEBP cuadrado de 512 × 512, fondo limpio, **sin texto**, la figura centrada y fácil de reconocer por un niño de 4 a 7 años. Nombre exacto del archivo. Después:

```
python3 tools/reading/syllables.py
python3 tools/reading/words.py
```
